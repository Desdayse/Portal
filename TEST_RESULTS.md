# Проверки — 2 ноября 2026

Среда: Windows 11 x64, Python 3.14.7, PySide6 6.10.2, PyInstaller 6.22.3.

- `python -m unittest discover -s tests -v`: 14 тестов прошли после добавления переключения режима. Дополнительный тест проверяет сохранение режима при смене координат, перезапуск и фоновое перемещение с удалением источника.
- `python -m compileall -q core ui main.py`: выполнено без ошибок.
- Сборка PyInstaller: создан `dist/updated/Portal/Portal.exe`.
- `python tests/smoke_exe.py dist/updated/Portal/Portal.exe`: собранный EXE загрузил Qt, создал главное окно в offscreen, запустил цикл событий и штатно завершился, код 0. Настройки изолированы во временной папке.

В файловых тестах использовались только временные каталоги. Qt-тест проверил создание, сохранение, восстановление и удаление портала.

Перетаскивание мышью из настоящего Проводника, отображение трея, визуальное качество на разных DPI, несколько мониторов и физическое отключение питания вручную не проверялись. Сценарий ручной проверки приведён в README.

Исправлена ошибка упаковки: сторонняя ICU из Poppler попадала в сборку и перекрывала системную Windows ICU. `Portal.spec` исключает эту несовместимую библиотеку.
