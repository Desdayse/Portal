# Portal 0.1.0

Первый выпуск настольной утилиты для передачи файлов через плавающие порталы на Windows 10/11 x64.

## Установка

1. Скачайте `Portal-Windows-x64.zip` из вложений релиза.
2. Распакуйте архив полностью.
3. Запустите `Portal/Portal.exe`. Python устанавливать не нужно.

## Первые шаги

Создайте портал, выберите папку и перетащите файл на портал из Проводника. По умолчанию файл копируется, а исходник остаётся. Для переноса выберите портал → «Режим передачи» → «Перемещение». Можно также нажать правой кнопкой по плавающему порталу.

Окно приложения закрывается в трей; полный выход — через меню значка возле часов. Для обновления сначала завершите старую версию через трей. Настройки сохраняются в `%LOCALAPPDATA%\Portal`.

## Проверка и ограничения

14 автоматических тестов прошли. Проверен запуск собранного EXE. Перетаскивание из Проводника, несколько мониторов и разные DPI требуют ручной проверки. Подробности и особенности сохранности данных описаны в README.

Программа не поддерживает передачу символических ссылок и junction, автоматическое восстановление после сбоя и отмену перемещения. Не изменяйте исходные файлы во время передачи.
